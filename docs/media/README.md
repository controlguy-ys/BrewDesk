# Capture notes

These assets show BrewDesk 0.2.0 running on macOS. The walkthrough is a live screen recording: all app interactions were performed through Computer Use, while macOS recorded the screen region occupied by the application window. It is not a slideshow or a simulated interface.

The walkthrough demonstrates the installed list, a filtered package and its details, a removal confirmation that is cancelled, and immediate English/Korean language switching. Package names, available versions and counts are a point-in-time snapshot of the recording Mac.

The recording is silent. It has no generated footage, narration or music. No package upgrade or removal is executed for the demonstration. The video uses a 16:9 delivery frame and preserves the complete app window.

Story DNA for this technical walkthrough:
- 누가: A Mac user with Homebrew-installed apps and tools.
- 무엇을 원하는데: Inspect packages and understand an intended change before running it.
- 무엇 때문에 안 되는가: Command-line output and package metadata are difficult to navigate together.

This is a software documentation recording, not a narrated social-media story. Spoken-script length targets and still-image production requirements do not apply to this continuous screen capture.
